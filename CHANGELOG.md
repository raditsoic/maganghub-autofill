## [0.1.0] - 2026-11-06

### Added
- Skill `maganghub-autofill`: drafts the three daily report parts (activities, lessons learned, struggles) from agent chats and git commits, then fills the MagangHub Monev form in the browser.
- No-ask mode that decides from evidence without asking questions.
- Writing rule W-11 and gate G-8: activities must use active `meN-` verbs.
- Marketplace catalogs for omp (`.omp-plugin/`) and Claude Code (`.claude-plugin/`).

### Documentation
- Form reload cause and safe fill procedure.
